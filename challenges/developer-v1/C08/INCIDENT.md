# Add behavioral regression tests for inventory event replay

Production inventory.cjs is the reference implementation for this test-writing task. Add executable node:test tests under test/ without changing production. stock is a nonnegative safe integer. An event has id (nonempty string), sku (nonempty string), delta (safe integer). apply(state,event) returns a new state; neither input is mutated. A duplicate event ID is ignored only for the same SKU. A new event records its SKU/id after a successful nonnegative-safe-integer stock adjustment. Invalid input or an adjustment below zero/above MAX_SAFE_INTEGER throws without changing input or recording the event. Tests must pass on the reference and detect meaningful behavioral regressions across identity, arithmetic and failure atomicity; importing the actual module is required.
